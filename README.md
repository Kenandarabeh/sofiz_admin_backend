# 💎 SofizAdmin - Financial Monitoring & Audit System

نظام الرقابة المالية والتدقيق المحاسبي الشامل لشركة **SofizPay**.
يهدف النظام لمراقبة حركة كل دينار وفلس داخل حسابات وبطاقات الشركة وكشف أي تسربات مالية أو أخطاء برمجية فور حدوثها.

## 🚀 التشغيل السريع (Docker):
```bash
cd /home/rabah/Desktop/project3/SofizAdmin
docker compose up -d --build
```
* لوحة التحكم: `http://localhost:8383`
* لوحة الإدارة: `http://localhost:8383/admin`
